# Syllabus topic list

`gs_topics.yaml` lists 65 topics used to tag past questions and, later, editorials. It follows the General Studies syllabus in the Civil Services Examination 2026 notification, one topic per syllabus line, plus four Prelims-led topics for areas the Mains lines do not name (ancient and medieval history, Indian geography, general science, other).

| Paper | Topics |
|---|---|
| GS1 (culture, history, geography, society) | 12 |
| GS2 (governance, polity, social justice, international relations) | 20 |
| GS3 (technology, economy, environment, security, disasters) | 21 |
| GS4 (ethics, integrity, aptitude) | 8 |
| Prelims-led | 4 |

Topic names and descriptions are written in our own words. The official wording stays in the notification, which the file links to.

This is version 0.1. It will change in the knowledge-base phase, when the full syllabus map (papers, topics and subtopics) is built. Topic ids never change once published, so existing tags stay valid.
